# Bi-Temporal Change-Detection Baselines

This directory contains the notebooks used to evaluate representative bi-temporal pre/post-event building-damage assessment methods against STRATA.

The experiments use paired pre-event and post-event imagery from the target events and follow the data partitions, label harmonization, annotation budget, and evaluation protocol documented in the main repository.

The included implementations may be adapted from official third-party repositories. The original repositories, publications, and software licenses must be cited in the corresponding notebooks and in `THIRD_PARTY_NOTICES.md`.
