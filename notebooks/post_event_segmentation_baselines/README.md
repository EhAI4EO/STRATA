# Post-Event Segmentation Baselines

This directory contains the notebooks used to train and evaluate the post-event semantic-segmentation baselines reported in the STRATA study.

All models use the same target-event subsets, validation data, label harmonization, and evaluation metrics described in the main repository. Model-specific dependencies and execution instructions are provided within each notebook.

U-Net:https://github.com/milesial/Pytorch-UNet
DeepLabV3+:https://github.com/VainF/DeepLabV3Plus-Pytorch
SegFormer-B2:https://github.com/NVlabs/SegFormer
Swin-U-Net:https://github.com/HuCaoFighting/Swin-Unet
U-NetFormer:https://github.com/WangLibo1995/GeoSeg
